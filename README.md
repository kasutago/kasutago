## Hola, soy kasutago 👋

Desarrollador **Python** y fan de **Linux**. Hago herramientas de escritorio, bots y
automatizaciones que resuelven problemas reales, y me gusta especialmente la
**IA que corre en tu propia PC**, sin depender de servicios de pago.

### 🛠️ Qué hago

- **Automatización con Python**: scripts para archivos, Excel/CSV y tareas repetitivas
- **Scraping**: extraer y ordenar datos de páginas web
- **Apps de escritorio** con GTK4 / libadwaita, Tkinter o Avalonia (C#)
- **IA local**: traducción automática (MarianMT, CTranslate2) y modelos de lenguaje con LM Studio
- **Ren'Py**: herramientas para novelas visuales y traducción al español
